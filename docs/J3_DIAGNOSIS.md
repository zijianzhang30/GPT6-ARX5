# J3 诊断（2026-09-22）

实机观察：J3 约 1.2° 时用户最终目标曾为 100°；SDK error_codes 为空，CAN 有接收，J3 SDK 电流读数曾约 5.55（未独立校准单位）。用户报告无明显异响、发热、卡住。不能仅据此排除硬件问题。

确认软件缺陷：LiveController 将 Controller.tick() 生成的指令位置每周期恢复成测量位置，下周期又从测量位置推进。位置滞后时，下发目标只领先一个周期，无法累计轨迹。现将 command_q 和实测 q 分开，保留限速/加速度、释放点动清除指令、心跳超时保护。指令与测量最大差值暂限 3°，避免不跟随时持续积累大幅指令；这不是厂商认证的安全或堵转保护阈值。网页新增下发角度与跟随误差。

测试：37 项 Python 测试通过，包含固定反馈下指令推进与上限、滞后电机跟随、释放点动、租约超时；JavaScript 语法检查通过。

部署：用户停止操作且反馈 enabled=false 后，通过 API 正常断开旧 SDK，重启在线 HTTP 服务。没有重连 SDK 或执行新的运动测试。实机修复效果仍需在用户确认工作区后初始化，并以低速、小幅 J3 点动验证。当前服务地址 http://127.0.0.1:8765 。
