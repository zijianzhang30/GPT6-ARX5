# 左臂抽取中间书本

2026-10-06新增独立任务。三本书平叠在蓝色盒子上，左臂抽取中间一本。用户明确成功标准为中间书相对书堆抽出约5厘米，其他书保持稳定，不要求完全取出。第1轮右臂仅辅助观察；第2轮用户新授权右臂抵住上方书，须作为独立变体记录，不能将该授权反写到第1轮。沿用共用流程的健康宿主、逐段视觉监督、三路MP4、回位、MD和用量记录。

## 操作判断

- 从互补视角确认目标是中间一本、可夹的突出边缘和上下书的支撑。正面书页白边重叠不能代替分层判断；必要时移动空的右观察臂取得侧视，检查整臂和线缆。
- 左夹指应包围目标书的可承力边缘，避免同时夹住上下书、只捏薄封面或书页。接近先核对上下/前后间隙，再分段闭合；夹爪开度不是力控。
- 沿目标书所在平面、朝已看清的空出方向抽取。先小段验证目标书是否随爪、上下书和盒子是否随动；卡滞、书页折弯、明显滑移或支撑物随动则停止推进，不以更紧闭爪或持续大拉力补救。
- 以书相对上下书/盒子的移动核验约5厘米，不能把机械臂指令位移直接当作实物位移。若仅有估计或TCP位移，标明量测限制。
- 达到目标后确认书仍有稳定支撑，再松爪、空爪撤离，至少两次新观察检查其他书及目标书稳定；分别完成参与运动的双臂回位。若支撑不明确，不自动完全抽出或让书悬空。
