# 拧螺丝任务：自主拾柱后旋下六边形螺帽 — 第1轮

## 冻结用户请求

先恢复拧螺丝任务的初始位姿，“然后先用右臂夹起螺丝柱的离右臂更近的一端，把螺丝柱夹起来之后，用左臂去夹六边形的螺帽，然后将逆时针旋转使得螺帽从螺丝柱上旋转下来”，然后按照我上面引号的内容更新一下之前的拧螺丝任务的skill，写对应实验记录的markdown文档，并且录制3路视频，这些操作和之前的十几个任务对齐就可以。

## 协议与证据边界

- 协议版本：20261011_near_end_pickup_counterclockwise_nut_removal。
- 新初态：银色螺丝柱/螺栓及六边形螺帽平放在绿色盒面，双爪为空。左右CAN沿用交换后映射：物理左5E5931/can0/8765，物理右765931/can1/8766。
- 原始关节参考复制自2026-10-05旋螺栓第1轮；原文件及哈希保存在return_reference.json和reference_provenance.json。该参考右爪曾人工预置持柱，夹爪开度不盲目复制。
- 顺序：原始位姿核验→右臂自主夹近端并试提→右臂呈递、保持→左爪夹六边形螺帽→分段逆时针退丝→螺帽完全旋下→分别放置→双臂回位核验。
- 逆时针观察方向：从螺帽外端沿螺纹轴看向柱体。首次小角度试转须核实螺帽相对柱体向自由端退丝；关节正负号不直接表示退丝方向。
- 成功：右臂自主拾柱且稳定持有，左爪夹住并将螺帽完全旋离螺纹。任务成功、物品放稳、最终回位分别核验。无规定旋转圈数或力矩。
- 三路录像：全局external、左腕gemini、右腕gemini_right；MP4，10fps，60秒分段。保留准备、恢复、失败、缺帧及人工介入。物理动作前检查新鲜帧、真实反馈与唯一保持宿主。
- 保留既有碰撞观察、人员进入复核、相机、通信、到位、限位、速度及预算保护。禁止用双臂接触未知时续预算、强拉或强拧绕过阻力。
- 2026-10-05旧轮“人工预置右臂持柱、左臂旋入3圈”的记录独立保留，本轮不继承其结果。
