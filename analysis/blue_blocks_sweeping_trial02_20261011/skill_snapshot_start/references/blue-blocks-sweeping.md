## 本场景的判定与方法

- 记录初始目标数和每个方块的位置，检查簸箕入口、边沿及固定材料。方块须全部进入内部，扫帚撤开后仍留在其中；被刷毛遮挡、停在入口或越过侧壁均需再观察。
- 当前协议要求自主夹取绿色盒旁刷柄；第1轮初始在左指之间属于人工预置历史。夹持须用有界试提和整把工具跟随证明，不能把闭爪或手柄投影落在指间当作抓起。
- 工具刷头伸出夹爪，路径复核须包含刷头、刷毛、手柄和簸箕边沿。夹爪TCP的轨迹不能直接当刷毛轨迹或接触压力；先核验刷头方向和桌面间隙，再进行短扫并观察方块实际位移。
- 以簸箕开口方向组织扫入路径，避免从侧壁硬推。簸箕若随动、刷毛明显卡在入口、工具滑移或方块连续没有朝入口进展，停止并重新观察；不连续增加下压来替代接触判断。
- 右臂授权仅为辅助观察，不自动改为抵住、夹持或移动簸箕。变换视角时左臂保持，一次只动一臂，检查全部连杆、相机及工具的空间。
- 任务目标完成、工具放稳、两臂回位分别核验。第1轮有监督成功证据，但不固化坐标或把单轮通过视为自主策略成功率。
- 薄手柄松爪后可能仍贴在一侧夹指。分步打开并小幅撤离，从静态背景比较工具是否跟随；工具直立不能证明已独立稳定。第1轮撤离后扫帚倾倒平放在空桌面，后续两次观察稳定；不得描述为精确受控平放。
