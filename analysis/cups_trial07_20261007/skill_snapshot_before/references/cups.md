# 双臂叠杯

## 目标与分工

左臂把第一个杯子放到指定叠杯点，释放、撤离并回本轮参考；右臂随后抓第二个杯子，套入第一个杯子，释放、撤离并回位。一次一臂。新图确认杯子尺寸/方向适合套叠，以及哪个杯子作为下杯，不能沿用旧摆放坐标。

## 阶段与判据

1. 左空爪对准第一只杯外壁、杯沿下方可夹部位；先看高度与前后间隙，再接近闭爪，避开薄杯沿，不把夹指插入杯内。接近末段分开校正方向，不能同时大幅前伸、横移和下降。
2. 小幅竖直试提：杯底离桌、杯单独随爪移动、姿态稳定才通过。首次空抓不算抓取成功，需回到支撑并重新校正夹持深度。
3. 移到指定点，下降至桌面支撑，逐步松爪、空爪撤离。新图确认下杯直立、独立稳定。
4. 左臂沿可见路径空爪回本轮参考并核验。必须同时确认完整臂体、腕相机和线缆退出右臂通道，才能开始右臂工作；仅抬开左夹爪不够。
5. 右臂抓第二只杯，试提通过后抬至杯底高于下杯杯沿，运输途中保持净空。
6. 悬空对准两杯轴线，缩小接近步长，分段套入。下杯倾斜、滑动或上杯卡边时停止推进；不能靠硬压或横拖找位置。
7. 上杯已有下杯支撑时逐步松爪，确认空爪后撤开；至少两次新观察确认套叠独立稳定。右臂回本轮参考，分别记录叠杯成功和两臂回位完成。

同轮局部重抓按共用流程处理。碰倒杯或疑似两臂接触时停止新动作，保留失败；人工重新摆放另记，不把摆好后的照片算机器人完成。
