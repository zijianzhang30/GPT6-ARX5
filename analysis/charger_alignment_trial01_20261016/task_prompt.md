# Exact prompt — adapter alignment, trial 1

Pick up the power adapter with the left arm and align its prongs with the socket holes closest to the left arm.

用户补充：右臂可以辅助观察，录制视频，记录调用次数等实验结果。

目标变体：拿起并悬空对孔。插入、通电和插入后的释放不属于本prompt。左臂操控，右臂仅按需辅助观察，不抵住插线板；一次只动一臂，检查完整连杆、夹指、相机与线缆通道。

新图目标：白色适配器在黑色托座上；桌面独立插线板的全局画面右侧蓝色组合插位，靠物理左臂的一组。不是墙面插座，不沿用历史靠开关组。最终使用其中与实物插脚匹配的插孔。

成功标准：适配器独立离开托座并稳定持有，能在互补视角中确认每根插脚分别对准目标插孔、方向一致且入口间隙可见；单张二维重叠或IK到位不能代替对孔证据。

回位参考继承上一轮原始实测基线，非厂商零位；原2.5度容差不变。
