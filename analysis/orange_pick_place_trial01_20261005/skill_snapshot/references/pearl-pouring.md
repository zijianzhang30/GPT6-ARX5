# 杯间倒珍珠：第7项

2026-10-05 第1轮：左臂从桌面抓源杯并倾倒，右臂辅助观察；用户验收成功，允许杯底残留。抓杯、受控放回及双臂回位有独立证据；发生洒落，接收数量未独立确认。分类尚未指定，不自动归入 L1/L2。

## 可复用的操作判断

- 先用杯内物判断源杯和接收杯。用户左右与相机左右可能相反：本轮源杯实际在全局画面右侧。按内容纠正映射并记入协议，不仅凭语言左右选择杯子。
- 夹杯壁后小幅试提，必须看到杯底离桌、杯子随爪稳定运动。本轮第一次闭爪只是推移杯子，补足前后距离后第二次试提才成功。空闭爪或到位通过不证明抓住。
- 将出料边缘与接收杯口对齐，兼顾前后距离、高度和实际落点。围绕 TCP 转动会移动杯口；全局投影重合不能证明三维对齐。右腕视角可能被左臂电机或相机支架遮挡，移动观察臂前检查整臂通道。
- 缓慢分段倾倒，首批出料后检查落点。落到杯外时先减小倾角止流，再调整，不能在偏位时继续加倾角。残留原因不清时不猜成粘附，也不以抖动或挤压强行清空。
- 接近关节限制时先离线评估其他姿态；保留原速度、到位和轨迹约束。本轮一次3°姿态调整被速度检查拒绝，拆成1.5°后通过。该数值是本轮证据，不是下一轮固定指令。
- 放杯前扶正，下降至桌面支撑再逐段张爪。杯沿通常比被夹的杯壁更宽：本轮第一次向上撤离仍带起杯子，先降回支撑面、继续张开，再沿杯侧向后撤离，最终验证独立稳定。不能把松爪命令完成当作释放完成。

## 记录及复用边界

从任务准备到回位录制全局、左腕、右腕 MP4；下一任务另开目录，不能覆盖本轮。健康保持宿主可在复核状态后续用，但新任务须保存新初态、回位参考和日志边界。不能为了切录像或切任务终止健康保持宿主。

分别写“用户验收”“视觉核验”“残留/洒落”“释放”“回位”。本轮用户原话：“算成功了把 最后那些珍珠也不好倒出来 我们就算成功拉”。允许残留是本轮验收条件，不能推广成以后所有倒料任务均允许洒落。

资源记录按 response ID 去重；缓存输入属于输入，推理输出属于输出。保存可取得的客户端条目时长和机器人命令耗时，服务器纯推理时间/TTFT不可取得时留空。观察、审核、工具往返和用户等待不能统称推理耗时。

## 新轮启动 prompt

> 使用 $arx-r5-tabletop-tasks 做一轮杯间倒珍珠：左臂抓起装有珍珠的源杯，将珍珠倒入指定空杯；右臂可辅助观察。先按杯内物确认两杯身份。自主用三路图像选抓点、路径和观察位；按已有清场授权继续，仅在新侵入、调整或无法排除的危险时停下。全过程录三路 MP4，记录 MD、公开对话、可取得的 token 与计时数据。发生洒落先止流并核对落点。完成后将源杯受控放回，验证释放与独立稳定，再按本轮初始参考回位。是否允许残留或洒落沿用本轮明确约定；没有约定时不默认放宽。
