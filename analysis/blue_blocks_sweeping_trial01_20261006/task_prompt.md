# 左臂用扫帚扫蓝色方块入簸箕 — 第1轮

协议v1，2026-10-06。用户要求左臂操作扫帚，将蓝色方块全部扫入收纳仓；现场目标是灰色簸箕，初始画面可见两个蓝色方块。右臂只辅助观察；不默认授权右臂抵住或搬动簸箕。

成功标准原话：“都 扫进去就算成功”。判定两个初始蓝块均越过簸箕入口并留在内部，扫帚撤开后独立稳定；接触、推动或只扫进一个不能计完整成功。
