## 过程与局部调整

1. 左爪按标准空爪准备张开，抬高、接近可夹花茎；单侧夹指两次带偏花茎，退开后改变深度和横向位置。右臂取得侧视。第一次闭至0.04后12毫米试提，未见花独立跟随，因此记首次局部抓取未验证。
2. 重新张开、沿可见空隙深入后逐步闭至0.04。第二次试提见花随爪运动；早期源杯轻微侧移，暂停侧压、重新居中后分段上提。确认整个茎端高于源杯口，杯体不再随动。
3. 将右观察臂分段收回原参考，再横向转移左臂，避免花茎、连杆和相机进入右臂空间。到目标杯上方后逐段插入，杯体直立。
4. 左爪从0.04渐开至0.059，再到0.079时花脱离夹持并明显向外倾斜。茎端仍在目标杯内，杯未倾倒。用户接受并要求收尾；左爪先后撤上提、向本臂侧让开，两次图像见姿态保持，随后分段回位。该开度和位移仅为本轮证据，不是通用抓取参数。
