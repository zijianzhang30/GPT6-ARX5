# 人工预置充电头后的剩余插入

这是用户明确选择的独立任务变体：充电头预先对准或浅插入靠物理左臂的匹配插位，左臂完成剩余插入，右臂仅辅助观察。省去取件，不能计作自主拾取或完整抓取插接成功。共用控制、三路录像、记录和回位要求仍适用；断电条件及插接几何见 [charger.md](charger.md)。

开始前保存能看见外壳底部间隙、两脚方向及对应孔口的初态证据。若已近乎贴合或剩余行程无法确认，不把人工摆好后的稳定当机器人插入。中途人工调整后取得新清场和新图，另记协议版本及局部尝试，保留本轮最初回位参考。

左爪需在避开插线板的高度包围绝缘外壳，双侧接触与姿态均可判断后才考虑沿孔轴推进。此变体不为了证明抓取而将预置插头拔出来试提。侧视看到金属脚不等于已证明两脚都进入正确孔；不以继续闭爪补偿偏心或不可见接触。

接触附近先离线核对所需小增量是否被当前控制接口接受。2026-10-05第1轮保留的最小 Cartesian 指令关节幅度为2°，3毫米向下候选只产生0.753507°最大关节幅度，因此预览拒绝、实机未推进。此门槛是当时的软件配置，不是测得的电机物理分辨率。不得放大或累加接触位移来凑门槛，也不得在实机接触中放宽保护。若合适的小步不受支持，应记录控制能力限制，另行离线研究与无接触验证，不能继续强压。

成功仍须有相对人工初态的实际插入进展、正确到位、释放和空爪撤离后多次独立稳定的证据。仅夹爪开合、关节到位或插头原位站立均不满足。
