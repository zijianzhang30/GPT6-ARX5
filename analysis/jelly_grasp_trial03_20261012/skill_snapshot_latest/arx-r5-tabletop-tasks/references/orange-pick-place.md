## 可复用的判断

- 先辨认完整水果还是单瓣、原支撑及可接触面。薄软橘瓣的经验不能直接当作完整橘子的夹持方案。
- 对准夹指的有效夹面。腕部图像中物体落在两指投影之间，仍可能位于夹面后方、靠近指根。本轮三次空提后改变右腕观察位置，辨清深度；先前前伸修正不合适，后退并降低才使夹面接触。位置数字只留作证据，下一轮重新观察规划。
- 用低幅试提检验：物体随爪移动、与支撑出现可见间隙，支撑本身不动。到位、夹爪闭合或图像投影重合都不等于抓稳。未抓起时先查深度与接触面，不反复加力挤压软水果。
- 抓稳后分段抬升并停稳复查滑移。本轮用户要求5–20厘米，指令累计抬升110毫米，关节反馈经运动学估算约91.7毫米；图像确认离面，但未用外部标尺测量。报告区分指令、反馈估算和视觉证据。
- 放回时降低到原支撑，分步张爪。确认物体已独立支撑、两侧脱离后再充分张开并垂直撤离；随后至少再观察一次稳定状态。本轮橘瓣略有倾斜，但始终在原支撑上，不能把姿态变化隐去。
- 复用健康宿主时保存新初态与回位参考，并冻结本任务日志片段。回位按本轮参考逐段执行，不能调用仍指向上一任务初态的旧回位入口。
