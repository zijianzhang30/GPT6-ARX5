# 原始prompt之后的授权变化

原始`task_prompt.md`保留不覆盖。

1. 用户“继续尝试，不要回位”：保留本试次，停止当时剩余回位、继续局部修正。人工转向后再次确认清场。
2. 成功抓放并停止进一步任务动作后，用户“现在任务已经成功了，你先停止视频录制，然后快速回位巴”：用户验收成功，并明确授权最终回位，优先于此前不回位；录像保持关闭，运动防护未放宽。
3. 用户“你把这次的结果导出为一个90秒的视频，告诉我路径”：完整停录前时间跨度三视角等比加速，另存原片之外；不把未录制的回位补成现场视频。
