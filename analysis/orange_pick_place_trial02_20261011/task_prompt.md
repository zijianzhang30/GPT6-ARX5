# 橘瓣抓放 第2轮冻结协议

用户：先恢复抓取橘子任务的初始位姿，按之前skill建立MD及3路MP4后执行，注意双臂不要碰撞。

场景：绿色盒顶的剥皮橘块/橘瓣，近景继续确认具体形状；不是完整带皮水果。左臂自主抓取，低幅试提证明离开盒面，抬升5—20厘米后放回原支撑；释放撤离后独立稳定至少两次，最后双臂回原任务参考。右臂保持，可在整臂路径清楚时辅助观察。逐段视觉监督、一次只动一臂；保留全部健康、预算、速度、到位保护。新任务恢复三路录像，上轮“回位不用录像”仅针对已完成的倾倒回位。

原参考继承2026-10-05橘瓣第1轮，原文件哈希保留；现有姿态先与它比较，已在原2.5°内时直接两次核验，不为表演回位而额外运动。单瓣/橘块及平盒变体独立记录，不沿用旧成功率。
