## 抓放与判据

1. 用全局及腕部新图区分果冻、包装、绿色支撑盒和夹指有效接触面。当前若为带盖果冻杯，夹取杯身并保持包装完整；若换成裸露软果冻，重新判断接触，不把包装杯与软果冻的夹法混用。
2. 左臂分段接近，对齐高度、前后深度与夹面，再小步闭爪。避免碰盒沿、夹起支撑或只勾住盖膜；开度位置不能当作夹持力测量。
3. 低幅试提确认果冻随爪移动、与支撑出现可见间隙、支撑独立不动。夹爪闭合、到位或二维重叠均不证明抓稳。同点连续两次失败则停止重复，重新获得深度/抓点依据才局部调整。
4. 抓稳后分段抬升5–20厘米，停稳复查滑移或变形。区分指令高度、反馈FK估算与视觉离面证据；无标尺时不声称外部精确测量。
5. 降回原支撑，分步松爪，确认受支撑后撤空爪；至少两次相隔数秒的新观察确认独立稳定。包装杯若倾倒、滑落或支撑移动，分别如实记录。
6. 沿已检查通道分段回原参考，两次核验。抓起、抬升、放回、独立稳定和回位分别记结果。正常停止三路录像并验证片段；保存实验Markdown、公开对话及可取得资源耗时，遵循[记录与证据](../arx-r5-tabletop-tasks/references/records-and-evidence.md)。

## 双臂间隙与恢复

一次只动一臂，另一臂保持；观察臂移动前检查全部连杆、夹指、相机、线缆与工作臂通道。没有有效第二视角时先补观察，不以IK通过代替碰撞检查。先离线规划，再单独取得并实际审阅新图，再下发一段；保留既有相机、心跳、速度、到位、跟踪与预算保护及额外规划余量。

现场新摆放、人工调整或人员侵入后复核本次清场；已有效确认且现场未变时不重复询问。故障或不明接触时暂停新动作、保存证据；禁止循环重连或重复故障轨迹。停止录像或写文档不能关闭健康保持宿主。
