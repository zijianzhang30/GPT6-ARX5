# 夹取果冻 · 新协议第1轮

## 用户原话

现在进行一个崭新的任务：“夹取果冻”，这个人物和“抓取橘子”这个任务几乎一模一样，只是把橘子改为了果冻，所以其余配置均同橘子，你需要先恢复抓取橘子任务的初始位姿，然后写一个新的“夹取果冻”的skill，模仿之前的抓取橘子任务的skill，写对应实验记录的markdown文档，并且录制3路视频，这些操作和之前的十几个任务对齐就可以，然后这些准备好后开始正式按照“夹取果冻”的skill执行即可，注意双臂不要碰撞

## 冻结协议

左臂抓绿色盒面上的果冻，先试提确认，再抬升5–20厘米并放回原支撑；右臂可辅助观察，一次只动一臂。原始回位参考逐字节继承橘子任务，原2.5°容差两次核验。全局、左腕、右腕MP4，10 fps、60秒分段。当前对象为完整包装杯，不开封。新协议只授权一轮。
