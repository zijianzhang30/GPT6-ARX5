## 可复用方法

1. 复用共用健康保持、三路 MP4、原保护和清场流程。本任务两臂都操作物体，一次只动一臂；不能沿用“右臂只看”。先辨认帽/身分界和笔轴，记录预置、松帽等真实初态。
2. 固定持笔臂，让空爪在可见通道中对齐帽段。全局图看指尖是否真正到达，腕图看帽段是否进入两片有效夹面；二维重叠不代表包围。第4轮曾过早闭爪，用户指出仍有距离；重新张开、向全局画面左侧并朝全局相机侧接近后才获得有效夹持。这个画面方向仅为本轮证据，不能转换为后续场景的固定坐标或正负号。
3. 逐段闭爪，每段看帽段是否居中、有无被顶歪。开度是位置，不是夹持力。不要用持续收紧弥补没到位；人工碰动后重新核实本次清场和新姿态，不把人工造成的转动都归因于机器人滑移。
4. 夹持前离线预检沿实际笔轴的短退出动作；保留当前命令 TCP 基准和原跟踪/到位判据。帽、身共同受约束时不横向掰折、不盲目旋扭、不用 renew 重锚目标。单步被门槛拒绝不构成放大接触动作的理由。
5. 当前用户协议以右臂固定笔身、左臂沿轴向摘帽为准；第4轮历史使用左爪固定帽、右爪带笔身退出。分别跟踪“帽相对左爪”和“笔身相对右爪”：帽随笔走说明留帽未通过；帽留住但笔身在右腕画面里相对夹指滑动，说明持笔未通过，也不是分离。发现滑移先停止拉拔，定位失效侧；接触位置和支撑清楚时可在原限额内小幅调整该侧开度，再用有界动作验证。再次滑移、弯曲、可疑干涉或无进展就停，不循环加紧或加大拔力。
