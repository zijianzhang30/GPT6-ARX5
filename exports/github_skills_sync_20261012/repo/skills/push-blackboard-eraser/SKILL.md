# 推黑板擦

使用左臂把黑板擦沿桌面推入红色方格。右臂仅按需要辅助观察；一次只移动一臂，检查两臂全部连杆、夹指、腕部相机、线缆与桌面物体的间隙。

## 执行方法与成功判据

1. 辨认黑板擦本体、完整红色方格边界和桌面支撑；新摆放/人工调整后按共用流程复核清场。已有有效确认且现场未变时直接续行。
2. 首次运动前建立全局、左腕、右腕三路MP4；检查manifest、设备身份、心跳及新鲜帧持续增长。按冻结参考分段恢复初始位姿，双臂实测和指令均按原2.5°容差核验。
3. 选择黑板擦背向目标区域的一侧，以夹爪外侧或指端侧面短段平推。保持黑板擦由桌面支撑，夹指不包夹、不提起；先在物体外调整接触姿态和开度，避免刮桌、压顶翻转或夹住黑板擦。
4. 每段都先规划，再实际审阅三路新图及反馈，最后单独下发。三路中至少用有效的第二视角判断擦体底边、接触侧和方格关系；右臂需要换观察位时左臂保持，右臂不越入左臂通道。
5. 用黑板擦相对桌纹与红线的真实位移判断进展。目标是黑板擦整个支撑轮廓进入方格；进入后及时停止推送，空爪撤开，以两次相隔数秒的新观察确认仍在方格内且独立稳定。未要求居中或固定朝向；若尺寸不允许完整进入或用户另行放宽标准，单独记录，不自行改变判据。
6. 成功、失败与回位分别记录。按原参考受控回位核验，正常STOP封口并验证所有视频片段，保留原始事件、多视角关键帧、公开对话及可取得的资源耗时口径。

## 接触与保护

- TCP高度不代表指尖实际离桌高度，IK/到位通过也不证明无碰撞。先留可见间隙，再小段接近、观察响应；不得以持续下压代替几何确认。
- 连续两段推送无进展时先停推；获得新的接触侧/高度/视角依据后才局部调整。不明接触、翻倒、卡滞、整臂间隙无法确认或保护故障时暂停任务，保留证据，按共用流程处理。
- 保留当前相机、心跳、速度、关节余量、跟踪、到位及会话预算保护。使用真实宿主预算做离线预览，原40°会话范围外留3.5°规划余量；仅健康静止且无不明接触时续段renew，之后重新观察/规划。
- 不自动增加试验轮次。历史推蓝块入三角的经验只用于判断方法，不能视为黑板擦新任务成功或直接回放坐标。

### 本轮可复用教训

- 先区分擦体顶面投影、底部支撑边和红线，不能只凭顶面中心或单视角重叠判成功；撤爪后用全局和有效腕视角复核。
- 长条擦体可能在侧推中转为前后向。端面斜推容易只平移；在新观察确认接触后，长边靠一端的短侧推可转向。此轮左54–58有效，历史坐标不得直接复用。
- 前侧补推若偏向一端会带来反向旋转；先撤开，再改变接触点。此轮左64偏转，左68改为前侧另一端后完成入框。
- 左37/38下探出现J2近乎不变、跟踪残差增大，停止继续下降并抬开后恢复；不能排除桌面接触，根因未确认。到位通过不等于无接触，不以连续下压补偿高度误差。
- 右臂观察位置应先为工作臂通道留空；左臂撤开后，可在不干涉路径分段恢复观察臂并获取完整目标视角。一次只动一臂、检查全部连杆和附件。
- renew会采纳实测关节作为新指令参考，可能使TCP参考产生变化；健康续段后必须重新观察、规划，原回位参考始终冻结。
