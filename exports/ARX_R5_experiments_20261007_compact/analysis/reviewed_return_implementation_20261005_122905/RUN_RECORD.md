# 受检回位入口实现

用户建议增加软件保护，在出现问题时回到最初位置。已经说明失能后不能靠电机回位、失联或卡住时不能盲目回位；实现限定为仍健康、带电静止、经视觉确认空爪和路径的正常回位入口。

新增reviewed_return.py并接入held_policy_review.py的reviewed-return-step命令。每段绑定新观察，复制并保持宿主初始参考，沿用原有有界回位规划、跟踪余量、到位和预算保护；完成后保持使能，不自动失能、不改夹爪、不自动续预算。视觉和录像字段为调用者的核验声明，不能伪装为自动传感器认证。

新增11项回位单元测试和2项宿主分发/故障测试，合并相关原有检查后130项通过，全部使用模拟硬件。首次组合测试因一个测试模块名写错而加载失败，更正模块名后全通过；没有为此修改保护判据。详见validation.json和源审计。后端、监督器、worker、原故障异常处理均保持原样。

实机没有启动、没有使能或运动，没有新录像。当前机械防坠情况仍仅有用户概括性确认，具体安装/测试事实未提供；最近新图中还有桌边前臂。软件实现不是本次物理恢复验证，也未解决失能后的承托问题。

使用说明见项目REVIEWED_RETURN.md。旧回位入口保留兼容，本次检查仅覆盖新命令，不能声称所有回位路径都已改造。
