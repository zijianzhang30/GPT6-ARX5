# 擦黑板演示参考

来源：[原文件](../../../OMITTED_FILES.html#320449d3ab46bec6)，9.2秒、30fps、276帧。来源路径、尺寸及SHA-256见[source.json](source.json)；抽帧概览见[overview.jpg](overview.jpg)。

0秒黑色软布在人手中，约0.8秒布面接触平放的绿色板面；随后沿文字方向来回擦，4.2秒移向另一端，5.5–7秒覆盖剩余区域，8.2秒抬布离开。结束时原字迹明显减少。另一手始终扶住板框。

可借鉴的是让较大软布面接触、短行程往复再换区域、完成后抬离观察。人手面压、压强及实际轨迹未经量测；不能把视频动作直接当机械臂轨迹或夹持力指令。机械臂先验证布与夹指一起离开支撑，再使布而非裸露夹指接触板面，以短行程检查字迹与板框响应；不在布滑移或板框明显滑动时继续加压。

本任务用户指定左臂操作。演示中的第二只手扶板不能自动转换成右臂接触授权；右臂只观察。当前预置黑布已搭在左爪前，须与自主从桌面取布区分。演示成功不是机器人成功，擦拭结果以本轮开始/结束固定视角图为准。
