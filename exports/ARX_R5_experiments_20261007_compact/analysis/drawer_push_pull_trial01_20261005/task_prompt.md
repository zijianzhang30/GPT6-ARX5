# 第9项：抽屉平稳拉出、推回，2026-10-05 第1轮

用户目标：左臂抓持抽屉可操作部位，沿滑轨平稳拉出约5厘米，再沿原方向推回约5厘米至本轮初始位置。右臂只辅助观察。

自主使用全局、左腕、右腕视图判断接近、把手/抽屉面接触及滑轨方向。一次只动一臂，不以末端位移冒充抽屉实际移动；同时观察柜体是否滑动/倾斜。保留所有原有保护；不明接触、卡滞、柜体随动或不能确认抓持时停止推进并记录依据。未配置已验证的接触力控，不以更大力强拉强推。

开始前新建回位参考与本轮日志边界，验证三路MP4正在记录。完成后验证抽屉回到原位置、夹爪释放与撤离，再将两臂按本轮初始姿态回位。结束后保存实验MD、公开对话、可取得的token与时间、任务skill经验，以及上排双腕/下排全局的三路合成视频。

本轮分类待定，不继承前五项L1或第六项L2分类。初始图中抽屉为桌面右侧的绿色抽屉/白色收纳结构，实际可抓取部位与轨道方向仍需视觉核验。

## 用户目标澄清

用户原话：“就第一次层那个抽屉 有一点打开的那层”。本轮目标是已经略微打开的那层抽屉，不把底座或未指定层作为替代。相对于本轮该层初始开度，拉出约5厘米，再推回约5厘米；不强行推过初始位置。

## 初始物体识别更正

后续三视角确认：目标为白色收纳柜上层已略开的抽屉，内有蓝色、绿色件；绿色部分是柜体底座。初期“绿色抽屉”描述不作为目标定义。按用户指定的已开层执行。
