# 离线资料包使用说明

先完整解压到本地文件夹，再双击 [index.html](index.html)。所有阅读页、目录页和媒体链接使用包内相对路径；文件夹整体移动后仍可使用。目录名较长时，建议解压到磁盘根目录附近。

本包包含报告对应的18类任务/变体、21份主实验记录、各轮准备/执行/失败/收尾证据、全部已找到的相关原始视频与合成片段、照片、prompt、公开对话、机器人事件日志、耗时/token数据及任务skill。视频文件数包括分段与不同机位，不等于试验次数。

早期只有照片或AVI的试次按原格式保留；录像缺口、损坏原件及恢复副本以原记录为准。浏览器不能播放AVI或某些MP4编码时，可用本地视频播放器打开。打包不重新编码、不补造缺失帧，也不改变成功/失败结论。

Markdown 阅读页扩展名为 .md.html；.md保留可编辑文本。复制时将链接改成包内相对路径；原始本机绝对路径仍可能出现在日志字段和代码示例中，作为来源说明，不是可在另一台电脑运行的地址。历史skill快照缺少的引用不会用当前skill冒充，统一列入 MISSING_REFERENCES.csv。

MANIFEST.csv记录每个源文件、包内路径、源内容和包内内容SHA-256及文本修改类型。source_audit.json是打包前源记录的审计，因此其哈希不必等于已改写链接的便携Markdown。符号链接按目标内容保存为普通文件。已知凭据若出现只脱敏其值；不收集本机账号配置或Codex内部会话。

本包是资料快照。历史PID、端口、机器人坐标、控制命令、健康状态及skill示例仅用于复盘，不代表当前状态。阅读资料不需要执行任何Python或Shell脚本。

项目原计划与实际记录日期、人工辅助条件、未完成任务及费用/仿真/多本体等材料缺口，见汇总报告。本地文件齐备不替代数据公开范围的项目确认。
