# L1 挂帽第 3 轮 — 冻结 prompt v1

用户授权：可以的 你启动抓取把 在尝试一下。

左臂从当前桌面独立抓取黄色空顶帽，挂到最低实际挂杆；右臂只辅助观察。帽圈已由用户转到展开、开口朝上状态，帽檐朝全局画面右侧。自主选抓点和持帽朝向，用三路相机判断，不把几何/成功核验交给用户；新侵入时停动复核。独立离桌且持续稳定才记抓取，杆端穿过开口、释放撤离后独立挂稳才记挂放。原保护、速度、预算和2度最小笛卡尔指令关节变化过滤不变；不为通过过滤扩大近接触试探。

连续复用健康带电宿主；第2轮两臂尚未完全回位，第3轮保存新的初态但继承第2轮不可变回位参考。新建三路MP4、阶段记录、公开对话与耗时统计。结束受控空爪回原参考，正常停止并验证录像。
