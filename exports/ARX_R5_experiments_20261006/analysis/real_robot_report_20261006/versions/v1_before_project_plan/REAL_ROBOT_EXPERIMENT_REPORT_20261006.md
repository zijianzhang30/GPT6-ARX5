# ARX R5 双臂桌面真机实验报告

**实验范围：2026年10月1日至10月6日；报告日期：2026年10月6日。**

**结论：系统已在部分桌面操作中完成从物体操作到撤离、回位的监督执行流程；精密插接、螺纹旋合、稳定抓持及故障后保持仍是主要瓶颈。** 本次汇总18类任务或协议变体，其中9类存在满足相应验收条件的案例，9类尚无目标完成证据。这个分类数量不是总体成功率，也不代表9类任务已形成可重复的自主技能。

报告依据本地逐轮MD、状态、图像、视频验证和用量记录。用户提供的[飞书文档](https://sxavxhkemv.feishu.cn/docx/AteSdzDw8o7uxLxQ7HBcsoYMnQf)当前跳转到登录页，未取得正文；本报告没有引用或假设其内容、模板或结论，也未修改原飞书文档。

## 1. 实验目的与执行方式

验证ARX R5在真实桌面场景中的操作能力，覆盖抓放、套叠、插接、倾倒、双臂分离、旋盖/旋螺母、抽取、擦拭与推动。除物体目标外，同时检查释放后稳定、空爪撤离、受控回位及证据完整性。

执行采用Codex逐段读取图像与机械臂反馈、生成有界动作、检查执行结果后再决定下一步的方式。有人现场监督并提供清场、人工布置或验收信息。**这是一组视觉监督真机实验，不是训练完成的端到端自主策略测试。** 局部重试保留在对应轮次内；目标、道具或初态变化保留协议版本。

用户曾把前五项归为L1、双臂拔笔帽归为L2；后续多数任务分类未指定。本报告的序号仅用于索引，不新增能力等级或认证。

## 5. 代表性成功案例

### 5.1 叠杯与笔入宽口杯：分阶段核验的价值

叠杯第3轮完成左杯放置及左臂回位后，再执行右杯套叠、释放和右臂回位，避免两臂同时占据操作空间。笔入杯的可重复成功主要来自粗笔与宽口杯变体；总序号7有整轮无场景介入证据。两项共同说明：先验证抓稳、留出操作通道、释放后复查，比只追踪末端是否到达目标更能支持成功结论。

### 5.2 橘瓣抓放：改变观察位后修正抓取深度

第1轮前3次局部抓取未成功。右腕换位后看到橘瓣位于有效夹面后方，调整前后深度和高度，第4次试提获得稳定随动，随后放回并完成双臂回位。该案例支持“视差用于解决抓点深度不确定”，不支持仅增加闭合量就能解决空抓。[证据记录](../../../../ORANGE_PICK_PLACE_EXPERIMENT_RECORD_20261005.md)

### 5.3 擦拭与扫入：目标与人工预置需明确

擦黑板第3轮以人工预置硬质板擦为初态，按“有接触擦拭动作、不要求字迹擦除”的新标准通过。扫块第1轮同样使用人工预置扫帚，2/2蓝块进入簸箕并在撤刷后稳定。这些案例证明对应条件下的工具运输/操作，不等同从桌面自主获取工具或已验证清洁质量。

### 5.4 本轮新增：夹爪边缘推蓝块入红色三角区

用户要求直接用爪边推动，不夹起方块。早期接触高度及前后位置不合适，部分动作没有产生有效位移；随后侧推将方块移到三角区边缘。用户指出尚未完全进入，系统保留未成功判断，撤开取得更清楚视图。改到后侧并先退开、再降低接触高度后，两段短推获得进一步位移。用户验收成功；空爪撤开后方块仍在区域内。

## 6. 未完成任务的主要原因

| 问题 | 直接观察到的事实 | 受影响任务 | 能支持的判断及局限 |
| --- | --- | --- | --- |
| 抓取几何不确定 | 空提、物体留在支撑、夹指与物体错位，或牵动支撑 | 果冻、挂帽、充电头、抽屉、抽书，及部分早期成功任务的失败局部尝试 | 优先问题是稳定抓持未建立；不能仅据闭合读数断言握力不足 |
| 接触侧/高度不合适 | 指尖从方块上方经过，侧推有效但到边界后需要改方向 | 推蓝块；与抓点选择有关的其他任务 | 需要真实物体位移反馈；空爪轨迹到位不能替代接触验证 |
| 旋转运动没有可靠传到物体 | 瓶盖单侧接触丢失、整瓶偏转，螺母早段随动后滑移 | 双臂旋盖、固定瓶身旋盖、旋螺母 | 未形成可验证的退丝/旋合；轴线对齐、夹面约束与摩擦是待验证因素，缺少扭矩测量不能定量归因 |
| 精密插入状态不可确认 | 二维对孔看似重合，但夹持、轴线、实际进入深度没有充分证据 | 插座、预置充电头、窄口瓶插花 | 需要更可靠的接触与深度判断；不能把停滞当插到底 |
| 工具接触面不稳定 | 软布悬垂、折叠，有短擦但字迹明显保留 | 软布擦黑板 | 未建立有效平整擦拭面；硬质板擦结果只能按新动作标准评价 |
| 控制链路/到位/SDK异常 | 到位拒绝、代理终止、反馈丢失、SDK错误与保护失能在不同轮出现 | 多个任务 | 必须按具体日志区分；不能统称网络故障、心跳问题或“模型与硬件冲突” |
| 双臂空间干涉风险 | 腕相机/末端接近同一操作区，用户多次提示路径干涉 | 叠杯早期、双臂旋盖等 | 先后顺序、观察臂退让和整臂通道检查有效；静态180°对向布局不保证旋转全程无干涉 |

这些记录反映当前夹持、观测与控制条件下的限制，不能证明相应物理任务无法完成。没有接触力、外部位置标定或重复对照实验时，原因分析保留“已观察事实”和“待验证机制”的区别。

## 7. 故障与人工介入的处理

本系列存在到位异常后失能下落、CAN/SDK无反馈、代理SIGTERM中断以及人工挪动后的保持丢失。它们不是同一种故障。部分任务结束且已保存回位证据后，设备又发生新异常，例如拔笔帽、擦板和扫块；这不覆盖此前已完成结果，也不允许把故障前的健康状态当成后续当前状态。

用户对承托/防坠处理提供过现场确认，但报告没有足够装置位置、承载试验曲线或独立测量材料，不将口头确认写成已完成工程认证。原始故障、人工介入和缺失录像均保留。人工摆放、松帽、预置工具或更改目标影响试验条件，应在未来固定协议重复试验中单独控制。

## 10. 后续实验建议与结论边界

1. 先冻结同一任务的初态、目标物、成功标准、人工介入规则和回位标准，再做多轮重复；对人工预置与自主拾取分别统计。成功案例数量不能替代重复性验证。
2. 对抓取问题先验证夹面包覆、试提与独立随动，记录失败抓点；对精密插入/旋合单独验证轴线、接触及微小位移响应，再恢复完整任务。涉及控制改动先做离线与空载验证，不在接触任务中放宽保护。
3. 继续用观察臂取得有效视差，同时把观察臂整条连杆和相机支架纳入通道检查；出现连续无进展时更换有证据支持的接触方案，避免同点盲试。
4. 分别追查到位判定边界、SDK/CAN链路和进程终止来源。恢复一次反馈不等于根因已消除；失能防护需有独立现场验证材料。
5. 保持本轮采用的证据规则，减少执行中非必要文档往返，统一每轮视频/动作/对话时钟及统计窗口，使下一轮耗时能被可靠比较。

当前最充分的能力证据集中在具有较大接触容差、可观察物体响应的操作，以及明确人工预置条件下的工具操作。精密接触与稳定抓持的限制尚未解决。报告中的成功是对应协议和证据范围内的成功，不是无人工辅助通用操作能力的结论。
