## 没有准确保存的指标

纯模型推理延迟、首 token 延迟（TTFT）、实际生成 token/s 缺少配套的逐请求起止/流式计时，不能由 token 事件时间或任务总时长准确倒推。不能把输出 token 除以整个实验时长称为模型推理速度。若后续需要这些指标，应在可观测的模型请求端记录请求标识、开始/首 token/结束时间、模型和 usage，同时单列工具、运动与人工等待。
