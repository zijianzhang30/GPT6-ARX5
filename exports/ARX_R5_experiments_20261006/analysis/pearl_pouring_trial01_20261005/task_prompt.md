# 第7项：杯间倒珍珠，第1轮（分类待定）

用户目标：左臂抓住桌面左侧装有珍珠的杯子，将珍珠倒入桌面右侧空杯；右臂可辅助观察。杯子左右以本轮全局初图为定位依据（源杯约图像x=302，接收杯约x=420），装填状态目前为用户提供、待视觉核实。物理左臂为can0/全局画面右侧，不能把机械臂左右与画面左右混淆。

复用arx-r5-tabletop-tasks共用流程及杯外壁抓取/试提方法，倾倒为新增未验证阶段，不照搬旧坐标。观察杯口与外壁，分段接近、闭爪和竖直试提；确认单杯稳定随动后运输到接收杯上方；逐段倾斜并检查落料、接收杯稳定和洒落。不能因没出料而未知接触摇晃、碰杯或突然加大倾角。完成后扶正源杯、放回可靠桌面支撑、释放并撤离，核验两臂返回本轮保存的最初参考。一次只动一臂，保留原保护；判断应基于三路新图而非用户代看。

三路MP4覆盖连接初始化、抓取、倾倒和回位；失败及人工介入保留。任务结束后集中整理MD、公开对话、状态、录像校验和耗时。记录逐response输入/缓存/输出/推理token与本地推理条目起止时间；客户端条目计时不等同服务器纯推理耗时，无法测量的TTFT/token每秒不填假数。准备/执行/人工等待/工具和抓图分开。

原始用户指令：
接下来我们做下一个任务 左边机械臂夹左边的这个杯子 桌面两个杯子 右边那个是空的 左边这个是有珍珠的我们需要夹杯子把里面的珍珠倒进右边杯子里面 右边的那个机械臂可以辅助观察 我们就还是按照之前的那些skill 记录实验md 还有录制视频？ 在把token 资源的消耗 推理时间也记录一下？

## 本轮协议更正与验收
开始观察后按杯内物识别：源杯在全局右侧、接收杯在全局左侧；用户描述的左右不能直接当全局图像左右。原始目标仍为将源杯内珍珠倒入空杯。
用户结束前明确接受剩余珍珠，原话：“算成功了把 最后那些珍珠也不好倒出来 我们就算成功拉”。记录为用户验收成功；中途洒落和未独立确认接收数量另记，不覆盖原始观察。
