## 共用要求（每个任务都适用）

执行用户指定的一轮，不自动追加。根据新鲜三视角和机械臂反馈自行逐步判断、修正和核验；保留原有速度与所有保护。一次只动一臂，检查整臂、相机、线缆和物体间隙。目标或摆放变化时重算，不沿用旧轨迹。

首次硬件动作前录制全局、左腕、右腕三路 MP4，并持续检查；保存 prompt、初末态、原始动作事件、关键图片和 MD，任务结束统一导出公开对话 MD。分别记录抓起、释放后独立稳定、两臂受控回位。收尾正常停止录像并验证文件，健康保持宿主不随录像一起关闭。

主动用三路相机探索抓点、路径与支撑关系；遮挡时先切换视角，必要时保持工作臂并让观察臂在安全通道内平移取得视差。常规步骤自行执行，不要求用户指方向、接管或代答“抓稳/挂入了吗”。已有清场和任务授权有效时自主继续。三路仍无法核验或出现接触/故障时停止新动作并记录具体阻碍；仅对视觉无法提供且执行必需的信息询问。

## 1. 叠杯

```text
使用 $arx-r5-tabletop-tasks 执行一轮 L1 叠杯验证：左臂先抓第一只杯子，放到指定叠杯点，松爪撤离并回本轮初始姿态；确认左臂完整退出通道后，右臂再抓第二只杯子套入第一只，松爪撤离并回位。两杯在释放后独立稳定才记叠杯成功。遵守本文件共用要求，录三路 MP4、记录任务和公开对话 MD。
```

## 2. 插笔（已有成功变体）

```text
使用 $arx-r5-tabletop-tasks 执行一轮 L1 插笔验证：左臂抓起露出的粗记号笔，放入黑色外壁、白色内壁的宽口杯。右臂可辅助观察，不扶杯或抓物。试提确认笔单独离开支撑后运输；松爪撤离后笔独立留杯才记成功，再完成两臂回位。遵守共用要求，录三路 MP4、保存任务和公开对话 MD。若现场不是此变体，先明确实际目标，不擅自换道具。
```

## 3. 插座（实验版）

```text
使用 $arx-r5-tabletop-tasks 执行一轮 L1 充电头插座验证：核实插线板市电插头已拔除，左臂从黑托座抓白色两脚充电头，目标为靠开关/电源线一端组合插位的两孔。右臂仅辅助观察，不固定插线板。看清两脚、两孔及侧面间距后分段尝试插入；不强压、不关闭保护。未成功如实记录，在支撑/路径明确时放回托座并空爪回位。遵守共用录像和 MD 要求，不做通电测试。
```

## 4. 插花（最后成功变体）

```text
使用 $arx-r5-tabletop-tasks 执行一轮 L1 插花验证：初态为左夹爪预先持花，不执行从支撑取花；把花杆放入红色纸杯内部，不要求插白色内衬的小孔，允许稳定倾斜靠杯沿。右臂可辅助观察。松爪撤离后花独立留杯、杯稳定才记成功，再完成两臂回位。记录人工预置，不计自动抓取。遵守共用要求，录三路 MP4、保存任务和公开对话 MD。
```

若改为窄口瓶或近似竖直，应在启动 prompt 中明确替换目标/姿态；这是不同验证条件，不能沿用纸杯成功结论。

## 5. 挂帽子（新增任务）

```text
使用 $arx-r5-tabletop-tasks 执行一轮 L1 挂帽验证：左臂先抓起帽子，再挂到架子高度最低的实际挂点，右臂可以辅助观察，不扶架、不抓帽。自行判断可夹部位和帽圈通过挂点的路径，避开立柱、支脚及其他挂杆；帽子独立离开原支撑才记抓取，释放撤离后仍独立挂在最低挂点且架子稳定才记挂放成功。两臂最终受控回本轮参考。录三路 MP4，记录阶段时间、重试、人工介入、结果及公开对话 MD；保留全部原保护，常规步骤自行判断。
```
