# 左臂插花 / 预先持花放入纸杯

## 先冻结变体

| 初态与目标 | 验证情况 |
| --- | --- |
| 从支撑自动取花→窄口瓶 | 曾抓起，但无完整稳定插瓶成功；有空抓、遮挡、干涉和运行故障 |
| 人工预先持花→窄口瓶 | 第 5 轮尝试过，开爪后花滑落桌面，不能记成功 |
| 人工预先持花→红色纸杯内部 | 第 5 轮最终完成独立放置与双臂回位，花倾斜靠杯沿 |

用户只说复用最后成功方案时，采用预先持花→纸杯。明确要求取花、瓶子或近似竖直时保留要求，不默默改成纸杯或删掉姿态标准。人工预置不算自动抓取，倾斜靠杯沿不算竖直插花。

## 最后成功方案

左臂在开始时稳定持有红花，目标是新图核实的红色纸杯内部；历史纸杯中有白色纸盒，用户明确无需瞄准纸盒顶部小孔。右臂只按需提供观察，一次一臂，不扶花、不扶容器。

1. 记录人工预置及清场，用新图核实花的夹持位置、杆端、真实杆轴和杯内可用空间。若花位姿变化，重新判断，不能继承旧开度/杆长/TCP 到杆端关系。
2. 在当前支撑关系明确的前提下短距离试提/复核保持，确认花随爪稳定。运输前看清整个花杆净空，绕开瓶子、杯沿、纸盒、观察臂及相机。必要时先退观察臂，再移动持花左臂。
3. 悬空对准杯内可用空间，侧视确认杆端前后间距。沿容器入口方向分段下降，每步看杯体有无移动、杆是否弯曲/卡住。历史下降总量不是新一轮目标。
4. 确认杆端在杯内且能转移支撑后，逐步开爪、观察是否仍被夹持或开始滑落。容器外掉落即未成功，不用继续张爪掩盖失败。
5. 花独立留在杯内、夹爪空后上撤，至少两次相隔数秒的新图确认杯和花稳定。单独记录花的实际倾角；只有用户接受的姿态要求满足才算本轮目标成功。
6. 左臂空爪分段回本轮参考，再让参与观察的右臂回位，各自核验。最后正常停止三路录像，导出对话 MD 与证据。

## 窄口瓶和取花的附加条件

取花需要确认支撑是松放还是固定，以及夹面真正包围可夹部位；花头投影重合或“再闭一些”不能代替抓取证据。小幅试提时花应单独离开、支撑不随动。不能夹住纸杯/纸盒强拉。

窄口瓶必须能看清花杆末端与瓶口的侧面间距；全局画面重合或用户说“进去了”不等于独立支撑已验证。已在瓶内/疑似接触时不通过横移或转腕硬调竖直；先在可见条件下沿进入方向解除接触，取得杆端与瓶口确实分离的多视角证据，再在自由空间调姿。瓶子随动说明仍可能接触，立即停止横移/旋转。

近似竖直应依据实际花茎相对桌面的方向，不依据夹爪姿态。柔性花杆会弯曲或在夹爪中转动；当前夹持和关节余量内没有可行路径时说明限制，不放宽保护、不把花抵住桌面/瓶口矫直。用户改目标/接受倾角后另记协议版本。
