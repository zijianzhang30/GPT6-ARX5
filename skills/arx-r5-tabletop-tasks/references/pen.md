# 左臂插笔 / 粗记号笔放入宽口杯

## 目标与版本

已有成功范例是露出的粗记号笔放入黑色外壁、白色内壁的宽口带把杯。原细笔从黑托座取出并插入笔筒是另一个变体，不能混算。用户指定细笔/笔筒时保留该目标，并说明验证范围；目标不明确时根据现场与用户语境确认容器。

左臂抓取和放置，右臂仅按需辅助观察，不抓物、不扶杯。初态曾用纸杯支撑，也曾让笔直接竖立桌面，必须以新图为准。粗笔模板优先复用已验证的裸露笔场景，不自动添加支撑或改道具。

## 阶段与判据

1. 空爪沿可见通道接近露出的中上部笔身。全局画面判断朝相机/远离相机的深度，左腕看夹面包围，必要时右腕提供侧视。笔必须进入有效夹面之间，指尖投影重合不够。
2. 分步闭爪、小幅竖直试提；看见笔底真正离开桌面/支撑、相对夹指不滑移，另取新图复核后才运输。历史开度 0.13 只是个例，不是固定答案或夹持力。
3. 先使整支笔避开途中障碍，再运输至真实杯口上方；姿态依据实际笔轴调整，不把 TCP 欧拉角累计值等同笔的角度。运输将接近观察臂区域时，左臂保持，先让右臂退到不干涉的位置。
4. 悬空核对笔端与真实开口的前后/左右间距，沿开口方向小步下降。笔端被遮挡、杯体移动、笔弯曲或卡边时停止推进，不能盲压或敲击找口。
5. 笔进入并转移至杯内支撑后逐步松爪，确认空爪再上撤。至少两次新观察确认笔独立留杯、杯稳定，才记录放置成功。
6. 空爪受控回本轮参考，右臂若参与观察也核验回位。放置完成后发生人工换场，仍记录其时间和范围，不称整轮无人介入。

碰倒/滑脱后的人工扶正必须记载，重新清场与新图核验后才继续。同轮空抓重试不改编号，不把托座随动或空爪提升算抓起。
