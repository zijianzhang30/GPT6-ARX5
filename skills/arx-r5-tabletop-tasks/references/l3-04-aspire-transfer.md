# L3-04 扫三个方块 · ASPIRE 仿真经验迁移

在本轮真机的 GPT 会话里加载本指南，用现场的全局和腕部画面定位。动作由 GPT6-ARX5 的受检监督宿主执行。开始前依次读[共用执行流程](common-execution.md)和[原有实机扫块指南](blue-blocks-sweeping.md)，核对本轮初态与当前标定。真机目标为**自主拾刷并把三个方块扫进固定簸箕**。左臂用刷，右臂按需辅助观察，一次只动一臂。

## 现场执行

1. **定位刷柄、方块和入口。** 用当前三路新图确认三个方块、刷柄、刷头、簸箕开口、入口边沿和可用通道。目标按当前实机坐标、夹爪和可用标定生成。若当前宿主使用仅提供 RGB 的 `image_grasp` 模式，用多视角相对位置和实测反馈分段接近。只有当前深度与坐标标定通过核验时才做米制反投影。位置或间隙仍不可判断时，停在可观察的位置。
2. **自主拾刷并确认工具相对夹爪的姿态。** 左爪先到刷柄附近的预抓取位，确认可下探后夹紧并小幅试提。用新图核对整把刷子随夹爪移动、刷子脱离原支撑、刷柄未滑移。试提后重新观察刷毛下缘、手柄伸出量和朝向，再据此规划扫掠。
3. **按簸箕开口组织短扫。** 每次选一个通道清楚的方块，从其外侧接近，让刷毛沿开口方向短扫。扫一段后核对方块位移和刷毛是否仍有效接触。通过入口前评估刷头、手柄和边沿的间隙，必要时先抬刷重新对齐，再从开口推进。过边沿后确认方块已完全进入；撤刷沿可见空通道，避免拖出已入箕的方块。
4. **根据回执和新图修正。** 规划拒绝时换一个有清晰间隙的接近姿态，并重新预览。动作结果未知、刷子滑动、刷毛卡住、簸箕位移或连续无进展时，暂停新动作，核对实时反馈和物体状态，再按共用流程决定是否局部重试。每段预览检查刷具、夹爪、腕部相机、连杆和对侧空间。现有实机预览为运动可行性检查，碰撞间隙仍需用现场证据核对。
5. **用撤刷后的画面验收。** 逐块确认三个方块均完全在簸箕内部，抬刷撤开后仍留在里面。入口压边、侧壁外露或刷毛遮挡时换视角复核。分别记录自主拾刷、最终入箕数、刷具释放和双臂回位。完成后按共用流程放稳刷子、释放、回位并封存三路录像。

## 证据与对照

- 仿真 System 2 历史轮在固定布局上接触了三个方块，原生评分确认 **2/3** 入箕。可复用的经验是试提后重估刷具姿态、按开口分段扫，以及撤刷后再核对方块。绝对位姿和指令序列供仿真复核。 [仿真试验与回放](https://github.com/LLM4Robot/LLM4Robot-Bench/blob/be281d2487da98ab87f81478a5e59623b8bf8e30/src/harness_v1/README.md#l3-04-system-2-pilot)
- 原有实机记录验证的是**两个蓝块**的监督扫入；本指南的三个方块迁移协议待实机验证。记录 `protocol=aspire_sim_transfer`、初始布局、模型与推理档位、人工干预、有记录的模型调用量及首帧到达标时间。和零样本对照时使用同样的三个方块、初态、模型、预算和验收口径。 [原有实机记录](blue-blocks-sweeping.md)
- ASPIRE 的 System 2 配方以可读技能描述接触策略、恢复和验收，并结合当轮观测生成目标。这里使用同样的经验迁移方式，执行接口由 GPT6-ARX5 提供。 [ASPIRE System 2 运行手册](https://github.com/NVlabs/ASPIRE/blob/main/docs/system2.md#reproduce-the-manipulation-demos)
